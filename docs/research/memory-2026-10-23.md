# Isolated history-memory measurements — 23 October 2026

Node v24.13.1, Windows x64. Commands use new temporary fixtures, not registered projects, provider homes or real data:

```
node --expose-gc scripts/perf-smoke.mjs --uncached --output tests/e2e/shots/perf-baseline-final.json
node --expose-gc scripts/perf-smoke.mjs --output tests/e2e/shots/perf-optimized-final.json
```

Fixture: a 1,000-conversation index and a 20,000-message transcript; 100 page opens spanning ten transcript ranges.
The uncached mode reproduces the previous whole-file read/parse method. Both modes validate page size. The optimized
mode uses bounded metadata/page caches and byte offsets, with signature invalidation after file changes.

| One paired run | Previous read method | Optimized reader |
|---|---:|---:|
| Wall time | 4,284 ms | 70 ms |
| Bytes read | 1,301,300,500 | 13,962,254 |
| Peak resident memory | 163,426,304 bytes | 110,968,832 bytes |
| Resident memory after explicit GC | 137,371,648 bytes | 109,072,384 bytes |

This synthetic run measured about 32% lower peak RSS and 21% lower settled RSS, with about 99% fewer bytes read.
It is not an idle whole-product RAM claim: browser, WPF host and providers are excluded. Garbage collection timing,
OS file cache and allocator retention vary. Small derived caches intentionally retain bounded data; cache accounting
uses serialized size rather than claiming an exact JavaScript heap measurement. The raw reports are ignored fixtures.

`scripts/perf-soak.mjs --minutes 30` completed: 1,800 seconds, 121 samples and 726 requests from six HTTP widget clients.
RSS started at 83,525,632 bytes and ended at 89,583,616 bytes (range 77,836,288–94,638,080). Listener count stayed at three;
engine children stayed at zero. Heap samples vary with collection; this is not proof that every workload is leak-free.
Raw evidence: `tests/e2e/shots/perf-soak.json`. Browser and WPF memory are excluded.

The browser component lifecycle check (`tests/e2e/component-soak.js`) passed 100 node-chat panel open/close cycles,
including immediate-close import races: zero retained intervals and zero retained chat listeners. The fix destroys
the mounted chat on Close and guards asynchronous mounting after disposal. Existing global listeners are excluded.

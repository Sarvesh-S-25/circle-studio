# Circle Studio walkthrough

GOAL: A new user can open a project, configure a team, send a useful brief, review proposed writes, and accept tasks with evidence.

OUTPUT: HyperFrames, 1920 × 1080, 30 fps, 100 seconds / 3000 frames.

LOOK: Circle Studio tokens copied from frontend/css/tokens.css. Ground #eeeeeb; ink #192323; accent #016e73. Inter 900 at 62px for headlines, 31px body, 160px outer margins. Actual sample UI in a 1110 × 680 viewport. Source logo on the closing card. No image filters.

MOTION: power3.out for the 15-frame screen entrance, 10-frame title reveal; 21-frame focus reposition after the first reading beat. Titles hold after settling. Linear progress rule, one per chapter. Hard scene cuts. No repeated floating motion.

SOUND: Carefree by Kevin MacLeod, 96 BPM, excerpted to 100 seconds, volume 0.65, 1-second fade in and 3-second fade out. No voiceover. Attribution on end card and CREDITS.md.

SHOTS: 0–5 hook; 5–15 connect tools; 15–22.5 open folder; 22.5–32.5 workflow; 32.5–40 agent role; 40–52.5 concrete brief; 52.5–62.5 file diff; 62.5–72.5 task evidence; 72.5–80 skills; 80–87.5 widgets; 87.5–95 reusable samples; 95–100 closing card.

BANNED: fabricated product UI, claims of real model execution, dark voids, gradients, glow, particles, serif headlines, three-card sales slides, moving readable titles, footage filters, a permanently docked logo.

QA: Check each scene midpoint and the opening/closing frames. Verify all asset requests, contrast, overflow, scene mounting, readable instruction holds, encoded duration/resolution/frame rate/audio. Sample agents and task entries are explicitly simulated; no real project files are written.

# Storyline choices

Chosen: **One project, one clear path.** A bakery website travels through a team, a concrete chat brief, file review, and task evidence. Real sample UI, petrol and graphite, readable sans-serif titles. Bright acoustic music at 96 BPM; no narration.

Alternative: **A day at the control room.** Follow requests arriving through Inbox and widgets, returning to the project when a decision is needed.

Alternative: **The review comes first.** Open on a proposed diff, then trace back to the brief and team that produced it.

The user requested a finished video, so the worked example proceeds directly to the file.
